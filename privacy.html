Privacy Policy - SATOS Calendar Sync

Last updated: 2026-10-28

SATOS Calendar Sync is a personal tool used only by its owner, Sat Nichapon. This policy describes how the tool handles Google user data.

Data accessed

With the owner's permission, the tool accesses the owner's own Google Calendar (scope: https://www.googleapis.com/auth/calendar). It reads event details (title, time, location) and creates or edits events when the owner asks.

How data is used

Calendar data is used only to show the owner a daily schedule summary and to add events the owner requests. It is not used for advertising, profiling or any other purpose.

Storage

The access token is stored only on the owner's own computer. Calendar data is not copied to any server operated by the owner or by third parties, except that summaries may be shown to the owner in the owner's private chat channels and processed by the AI model that the owner uses to produce them.

Sharing

Google user data is not sold or shared with third parties.

Revoking access and deletion

The owner can revoke access at any time in the Google Account permissions page, and can delete the stored token from the computer.
